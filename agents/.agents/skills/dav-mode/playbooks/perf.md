# Perf

1. **Get the baseline first, from the real surface.** A number you did not
   measure before the change is not a comparison.
2. **Profile before you theorise.** The bottleneck is routinely not where the
   room agrees it is.
3. Change one thing. Re-measure on the same surface, same input, same shape.
4. **A measured dead end is a result.** Write it where it would be re-proposed,
   so the next person does not spend the day again.
5. Run the behaviour guards too: a faster wrong answer is still wrong.
